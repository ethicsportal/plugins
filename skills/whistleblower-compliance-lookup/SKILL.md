# EU Whistleblower Compliance Lookup

EthicsPortal publishes a reference directory of how EU Directive 2019/1937 (the Whistleblower Directive) has been transposed into national law for every EU member state.

## Capabilities

- Country-specific transposition laws and effective dates
- Organization-size thresholds triggering reporting-channel obligations
- Protected reporter categories (employees, contractors, shareholders, etc.)
- Whistleblowing channel requirements under Articles 8 and 9 (timelines, acknowledgement, follow-up)
- Penalty schedules for non-compliance
- Comparison across providers for compliant reporting platforms

## Usage

Country pages follow a stable URL pattern:

```
https://ethicsportal.eu/whistleblower-laws/{country}/
```

Supported country slugs: `austria`, `belgium`, `bulgaria`, `croatia`, `cyprus`, `czech-republic`, `denmark`, `estonia`, `finland`, `france`, `germany`, `greece`, `hungary`, `ireland`, `italy`, `latvia`, `lithuania`, `luxembourg`, `malta`, `netherlands`, `poland`, `portugal`, `romania`, `slovakia`, `slovenia`, `spain`, `sweden`.

Additional references:

- Site-wide summary for LLMs: `https://ethicsportal.eu/llms.txt`
- Full-content dump for LLMs: `https://ethicsportal.eu/llms-full.txt`
- Compliance overview: `https://ethicsportal.eu/compliance/`

## Scope

Reference information only. The skill does not file reports, create cases, or authenticate users. Each organisation's whistleblowing channel runs at `https://secure.ethicsportal.eu`.
